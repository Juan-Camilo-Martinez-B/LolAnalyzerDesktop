# Changelog

## 1.0.0

Cliente de escritorio y overlay de LolAnalyzer para Overwolf.

- Tres ventanas: escritorio, overlay HUD-safe y background (LCU + eventos de partida).
- Dashboard de perfil, KPI, Tilt-o-Meter, campeones, historial y telemetría.
- Asistente de selección: composición, counters, bans y runas.
- Mini-HUD con tilt, CS/min, objetivos, opacidad y atajos.
- Ajustes de sensibilidad, posición, audio y diagnóstico del cliente de Riot.
- Barra SIM para probar sin League abierto.
- El reloj de partida ya no redibuja el dashboard en cada segundo.
- `npm run package:opk` genera `release/LolAnalyzer.opk` a partir de `dist/`.
